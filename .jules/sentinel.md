## 2026-07-28 - SSRF Prevention & Strict TLS Verification in Preflight Script
**Vulnerability:** `preflight-check.py` disabled SSL certificate verification globally (`ssl.CERT_NONE` and `check_hostname = False`) and lacked URL destination/scheme validation, allowing potential MITM attacks and SSRF against internal/loopback services or metadata endpoints (`169.254.169.254`, `127.0.0.1`).
**Learning:** Background preflight/validation scripts in this job processing pipeline accept user-controlled or scraped URLs directly. Without entry point URL scheme and IP range validation via DNS resolution, malicious or internal URLs can trigger internal requests.
**Prevention:** Always validate schemes (`http`/`https` only) and resolve hostnames to ensure target IP addresses do not belong to loopback, private (RFC 1918), link-local, multicast, or reserved ranges using `is_safe_url` in `queue_utils.py`. Standard default SSL context (`ssl.create_default_context()`) must be retained.
