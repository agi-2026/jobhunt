## 2026-09-15 - Enforce SSRF Protection and Standard SSL Verification Across Queue Utilities
**Vulnerability:** Job posting validation scripts and dashboard endpoints accepted arbitrary user-supplied URLs without scheme/IP validation, while disabling SSL certificate verification (`ssl.CERT_NONE` and `check_hostname = False`), enabling SSRF attacks against local/internal networks (e.g. AWS IMDS or localhost) and MITM exploitation.
**Learning:** Utilities in `workspace/scripts` (such as `preflight-check.py`, `batch-preflight.py`, `clean-queue.py`, and `validate-queue-urls.py`) and `dashboard/server.py` had disabled SSL checks for development testing and lacked DNS resolution checks.
**Prevention:** Always route external URL validation through `queue_utils.is_safe_url()` to enforce `http`/`https` schemes and block non-public IP ranges via `socket.getaddrinfo` and `ipaddress`. Keep standard SSL verification (`ssl.create_default_context()`) enabled across all network requests.
